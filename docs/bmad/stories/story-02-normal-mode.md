# Story 02 — Normal Mode Spin Loop, Reels, FUN POINT Scoring

## Story
As a player I want an unlimited, free, satisfying reel machine in Normal Mode that awards FUN POINTS for funny combinations.

## Acceptance Criteria
1. 3 reels, 8 symbols (🍒🍋⭐🍀💎🐔🥔🐟) generated by independent uniform RNG per reel. [UT: distribution]
2. No SIM COIN deduction ever in Normal Mode (no code path). [UT + AUDIT §29.4]
3. FUN POINTS: +10 any spin; +50 one pair; triples cherry 200 / star 500 / diamond 1000 / chicken 777 / potato 999; other triple +150. [UT]
4. Spin sequence per §14: validate → (no cost) → disable SPIN → reels start → stop 800/1200/1600ms → resolve → apply rewards → stats → result animation → re-enable. [GUI]
5. Result banner shows combination message; chicken/potato special events (§13, §18). [UT]
6. Normal stats updated per §21 (spins, FUN POINTS earned, symbol counts, triples, best streak, rare combos). [UT]
7. SPIN disabled while resolving. [GUI]
